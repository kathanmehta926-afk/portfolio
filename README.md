## ⚡ Highlights & Design Principles

Built with high visual precision inspired by **21st.dev**, **uiverse.io**, and modern engineering aesthetics:
- 🟢 **Crisp Light Green & Deep Dark Palette**: Zero tacky gradients — uses solid, high-contrast cyber-mint tokens (`#00e599`, `#10b981`), solid dark surfaces (`#070a09`, `#121915`), and crisp borders.
- 🎯 **Custom Magnetic Cursor System**: Dual-layer animated follower with magnetic snap on interactive elements.
- 💡 **21st.dev Dynamic Spotlight Cards**: Dynamic mouse coordinate tracking illuminating card borders on hover.
- 📊 **Interactive Project Sandboxes**:
  - **Student Performance EDA Explorer**: Live correlation and grade impact inspector.
  - **IMDB Dataset Query Simulator**: Pandas syntax and multi-decade cinema trends filter.
  - **DSA Sorting Visualizer**: Real-time animated Bubble Sort & Quick Sort engine built in JavaScript.
- 💻 **Interactive CLI Developer Terminal**: Fully functional Linux bash-styled command runner (`help`, `skills`, `projects`, `contact`, `clear`, etc.).
- 🔊 **Web Audio UI Synthesizer**: Subtle futuristic micro-click audio feedback with mute toggle (zero external audio files).
- 📱 **100% Mobile Responsive**: Tested down to 320px mobile screens with sliding drawer navigation.
- ⚡ **Zero-Build Vercel Ready**: High performance static architecture with 100/100 Lighthouse compatibility.

## 🚀 Deployment Instructions (Vercel)

1. **Push to GitHub**:
   ```bash
   git add .
   git commit -m "feat: complete modern portfolio with light green theme and interactive widgets"
   git push -u origin main
   ```
2. **Deploy on Vercel**:
   - Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
   - Select your GitHub repository: `kathanmehta926-afk/portfolio`.
   - Framework Preset: **Other** (Static HTML/JS).
   - Click **Deploy**. Your portfolio will be live in seconds with global CDN and SSL!
